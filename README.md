🌊 DeepSea NFT Marketplace

A decentralized NFT marketplace inspired by the depth and mystery of the ocean.

DeepSea is a full-stack Web3 application that enables users to mint, buy, sell, and explore NFTs securely using blockchain technology. Built with a focus on modern UI/UX and scalability, it provides a seamless experience for digital asset trading.


✨ Features


  🎨 Create and mint NFTs


  🛒 Buy & sell NFTs on the marketplace


  🔐 Secure blockchain-based ownership


  👛 Wallet integration using MetaMask


  ⚡ Fast, responsive, and modern UI


  🌊 Ocean-inspired design theme

  
  📦 Decentralized storage using IPFS

⚙️ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/ferese/deepsea-nft-marketplace.gitcd deepsea-nft-marketplace
2️⃣ Install dependencies
npm install
3️⃣ Start development server
npm start

🔐 Smart Contract Setup
Compile contracts
npx hardhat compile
Deploy locally
npx hardhat run scripts/deploy.js --network localhost
Run local blockchain
npx hardhat node

🧪 Testing
npx hardhat test
